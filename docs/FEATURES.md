# Features

## File Import

Users can import multiple local files from the browser. FilePilot creates metadata records and stores preview content when supported.

## Preview Support

Supported previews include:

- Images
- Text files
- Markdown
- HTML
- CSS
- JavaScript
- JSON
- CSV and logs

Unsupported files can still be organized and backed up as metadata.

## Collections

Collections help group files by purpose, project, topic, or type.

## Tags and Notes

Each file can have tags and notes. Tags improve searching and filtering. Notes help users remember why a file was imported.

## Duplicate Detection

FilePilot uses SHA-256 checksums to skip duplicate file imports.

## Dashboard

The dashboard shows total files, collections, favorites, tracked storage, recent imports, recent activity, file categories, and popular tags.

## Backup and Restore

Users can export the workspace as JSON and import it later.

## Offline Support

A service worker caches the app shell so the interface can work offline after first load.
